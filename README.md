# MSI Control for macOS

为运行 macOS 的 MSI 笔记本开发的控制工具，支持硬件监测、风扇控制、Mystic Light 键盘灯效、电池充电限制和快捷键。

本项目为个人开发，与 MSI 官方无关，不是 MSI Center 的完整移植。

## 兼容性

主要在 **MSI Crosshair 16 HX D14VFKG**、EC 固件 **`15P2EMS1.110`** 上开发和验证。通用 EC 功能参考 `msi-ec` 的固件配置，按识别到的固件和驱动能力开放。

| 项目 | 要求 |
|---|---|
| 系统 | macOS 14 及以上 |
| Liquid Glass OSD | macOS 26 及以上 |
| 架构 | Intel x86_64 |
| EC 控制 | 已加载兼容的 `MSIECBridge.kext` |

固件配置匹配不代表整台机器的所有功能都已验证。不同机型的 EC 寄存器、键盘协议和 CPU 能力可能不同；未知固件不开放未经适配的写入。配置范围见 [驱动适配说明](Drivers/MSIECBridge/PROFILE-SUPPORT.md)。

### 性能与散热

支持节能、安静、平衡、高性能、极致五个性能档位，以及自动风扇、自定义曲线和 Cooler Boost。兼容的 CPU 可调整持续与短时功耗上限，写入后会读回校验，并提供恢复原始设置。

ECO 开关仅在节能档位生效。开启后使用 EC 的 ECO 模式，部分机型可能同时关闭键盘灯；关闭后仍使用软件的节能功耗配置。各项控制是否可用，以当前设备识别结果为准。

### CPU 频率怎么看

点击仪表盘的 CPU 频率，可查看各逻辑核心的数据。P 核是性能核，E 核是能效核；支持超线程的物理核心可能显示为两条逻辑核心。

| 名称 | 通俗解释 |
|---|---|
| 运行频率 | 这个核心在“真正干活的时候”，平均跑得有多快。不把休息时间算进去。 |
| 有效频率 | 把干活和休息时间都算进去，这段采样时间内平均跑了多少。核心经常休息时，这个数会明显更低。 |

例如，一个核心干活时约为 **4 GHz**，但一秒里只工作了约四分之一的时间，其运行频率可能接近 **4 GHz**，有效频率则可能接近 **1 GHz**。这只是帮助理解的例子，不是固定换算规则。

- **有效频率低不一定是降频。** 轻负载时，核心大部分时间休息，这是正常省电行为。
- **频率不等于使用率，也不等于性能分数。** 不同类型核心即使频率相同，处理能力也不一定相同。
- 仪表盘显示各核按活动情况加权后的运行频率，不是最高核心频率，也不是所有核心的简单平均值。它不保证与 Windows 任务管理器数值完全一致。
- 数据来自驱动读取的硬件计数器，比较前后两次读数计算区间平均值，并非某一瞬间的倍频。应用约每秒更新一次；“等待采样”“空闲”或“暂不可用”不表示 CPU 停止工作。

**目前的频率限制：** 在测试用的 i7-14700HX 上，E 核在有负载时仍出现全部约为 **0.8 GHz** 的运行频率读数。已观察到计数器持续变化，但尚未确认是实际限频，还是参考频率及换算方式的兼容问题。暂时不要用这些 E 核读数判断是否锁频；它们也可能影响仪表盘的汇总频率。不能据此认定 CPUFriend 或某个性能档位是原因。

逐核采样依赖驱动与内核兼容性，目前全核缓存路径限于已核对的 Darwin 25.6 内核。其他系统可能没有完整逐核数据。第 12 代之前的部分 Intel CPU 已加入兼容处理，但未完成各型号实机验证。

### 键盘灯效

目前仅支持 **MSI Mystic Light 键盘**，不支持 SteelSeries 键盘。

支持纯色、彩虹、呼吸、色彩循环、波浪、舞动、色轮和关闭，可设置分区颜色，并在应用启动时恢复上次保存的灯效。

部分动画由应用持续运行，退出后不保证继续播放。“舞动”为预设动画，不随音乐或按键变化。

### 电池

支持读取电池状态和设置充电上限，不支持电池校准或自动充放电流程。

## 安装与 EFI

下载 Releases 中的软件压缩包，解压后将 `MSI Control.app` 放入应用程序目录。

普通启动不会修改 EFI。只有在应用中选择 OpenCore 配置并确认安装后，才会：

1. 备份 `EFI/OC/config.plist`。
2. 备份已有的 `MSIECBridge.kext`。
3. 将附带驱动安装至 `EFI/OC/Kexts/`。
4. 在 `Kernel → Add` 中添加或更新驱动条目，并启用。

当前软件版本为 **`0.3.49 (165)`**，附带驱动为 **`MSIECBridge 0.4.9 / API 15`**。更新或配置驱动后，需要重启并从对应的 OpenCore 启动。只替换应用不会更新当前运行的驱动；硬件驱动页显示的是实际加载版本。

安装器不会修改 SMBIOS 身份信息、启动参数、SIP、AMFI、ACPI 或其他硬件驱动，也不会调整 BIOS。

**操作前请保留可启动的备用 EFI。未适配机型不要直接安装驱动或执行 EC 写入。**

## 已知限制

- 实机验证主要基于上述机型，其他 MSI 设备不保证兼容。
- CPU 频率是区间估算；E 核读数及其他 CPU、内核的兼容范围见上面的说明。
- 部分硬件数据取决于 macOS 驱动是否提供读取接口。
- 不支持 MSI Center 的全部功能。
- 玻璃效果会受到系统版本、背景和无障碍设置影响。
- 驱动安装后仍需在目标机器上验证，编译通过不代表硬件功能已全部验证。

## 从源码构建

```sh
swift build -c release
```

需要 Swift 6 工具链；构建 Liquid Glass 界面需要 macOS 26 SDK。主程序输出位于 `.build/release/MSIControl`。驱动源码与说明位于 `Drivers/MSIECBridge`。

发布包使用本地持久证书签名，不是 Apple Developer ID 公证版本。源码不包含签名私钥或证书。

后台助手会校验应用签名。自行构建时，需要使用自己的持久签名身份，并同步调整 `Sources/PowerServiceProtocol/PowerServiceProtocol.swift` 中的签名要求；直接使用原配置构建的应用不能保证连接到发布版助手。
