# MSI Control for macOS

为运行 macOS 的 MSI 笔记本开发的控制工具，支持硬件监测、风扇控制、Mystic Light 键盘灯效、电池充电限制和快捷键。

本项目为个人开发，与 MSI 官方无关，不是 MSI Center 的完整移植。

## 兼容性

目前针对 **MSI Crosshair 16 HX D14VFKG** 开发，部分 EC 控制功能适配固件 **`15P2EMS1.110`**。

| 项目 | 要求 |
|---|---|
| 系统 | macOS 14 及以上 |
| Liquid Glass OSD | macOS 26 及以上 |
| 架构 | Intel x86_64 |
| EC 控制 | 已加载兼容的 `MSIECBridge.kext` |

其他机型尚未适配。不同机型的 EC 寄存器和键盘协议可能不同，请勿直接尝试硬件写入。

### 性能与散热

支持安静、平衡、高性能三个性能档位，以及自动风扇、自定义曲线和 Cooler Boost。

### 键盘灯效

目前仅支持 **MSI Mystic Light 键盘**，不支持 SteelSeries 键盘。

支持纯色、彩虹、呼吸、色彩循环、波浪、舞动、色轮和关闭，可设置分区颜色，并在应用启动时恢复上次保存的灯效。

部分动画由应用持续运行，退出后不保证继续播放。“舞动”为预设动画，不随音乐或按键变化。

### 电池

支持读取电池状态和设置充电上限，不支持电池校准或自动充放电流程。

OSD 不需要屏幕录制权限，也不读取壁纸或截图。模糊和折射强度由系统控制。

## 安装与 EFI

下载 Releases 中的软件压缩包，解压后将 `MSI Control.app` 放入应用程序目录。

普通启动不会修改 EFI。只有在应用中选择 OpenCore 配置并确认安装后，才会：

1. 备份 `EFI/OC/config.plist`。
2. 备份已有的 `MSIECBridge.kext`。
3. 将附带驱动安装至 `EFI/OC/Kexts/`。
4. 在 `Kernel → Add` 中添加或更新驱动条目，并启用。

当前附带驱动版本为 **`0.3.6`**。配置完成后，需要重启并从对应的 OpenCore 启动。

安装器不会修改 SMBIOS 身份信息、启动参数、SIP、AMFI、ACPI 或其他硬件驱动，也不会调整 BIOS。

**操作前请保留可启动的备用 EFI。未适配机型不要直接安装驱动或执行 EC 写入。**

## 权限

| 操作 | 要求 |
|---|---|
| OSD 显示 | 无需录屏权限 |
| 全局快捷键 | 可能需要输入监控权限 |
| 蓝牙控制 | 蓝牙访问权限 |
| EFI 挂载 | 可能需要管理员授权 |
| EC 写入 | 管理员授权及匹配固件 |
| CPU 频率读取 | 需要兼容驱动，日常读取无需管理员授权 |

## 已知限制

- 目前仅针对上述机型开发，其他 MSI 设备不保证兼容。
- 部分硬件数据取决于 macOS 驱动是否提供读取接口。
- 不支持 MSI Center 的全部功能。
- 玻璃效果会受到系统版本、背景和无障碍设置影响。
- 驱动安装后仍需在目标机器上验证，编译通过不代表硬件功能已全部验证。

## 从源码构建

```sh
swift build -c release
```

需要 Swift 6 工具链；构建 Liquid Glass 界面需要 macOS 26 SDK。主程序输出位于 `.build/release/MSIControl`。驱动源码与说明位于 `Drivers/MSIECBridge`。

发布包使用本地持久证书签名，不是 Apple Developer ID 公证版本。源码不包含签名私钥或证书。
